================================================================================
       RASPBERRY PI 4 - UNIVERSAL AUTOMATED SETUP SUITE (คู่มือการใช้งาน)
================================================================================
ยินดีต้อนรับสู่ชุดติดตั้งและปรับแต่งระบบ Raspberry Pi 4 แบบเบ็ดเสร็จ (ปี 2026 Edition)
ออกแบบมาให้ใช้งานได้ทั้งเครื่องใหม่ และเครื่องที่ต้องการปรับจูนให้พร้อมใช้งาน

[ข้อมูลการเข้าใช้งานระบบ]
- เครื่องหลัก (Primary) : 192.168.88.74 (RAM 1GB, หน้าจอเริ่มต้น: XFCE สไตล์ Windows หรือ PIXEL)
- บัญชีผู้ใช้เริ่มต้น     : Username: pi  |  Password: 1234

[วิธีใช้งานไฟล์ต่างๆ ในโฟลเดอร์นี้]
1. Control-Center.bat
   -> ดับเบิลคลิกเพื่อเปิดหน้าต่างศูนย์ควบคุมหลัก 18 เมนู (เชื่อมต่อ 192.168.88.74 เป็นค่าเริ่มต้น)

2. 0-Setup-Pi4-Automated.bat
   -> ดับเบิลคลิกเพื่อติดตั้งระบบทั้งหมดลงบอร์ด Pi (192.168.88.74) อัตโนมัติในคลิกเดียวจาก Windows

3. 1-Remote-Desktop.bat
   -> ดับเบิลคลิกเพื่อเปิดหน้าต่างรีโมทหน้าจอ Desktop (ความละเอียด 1024x600)

4. 2-SSH-Terminal.bat
   -> ดับเบิลคลิกเพื่อเปิดหน้าต่างพิมพ์คำสั่ง SSH คอนโซลควบคุมบอร์ด

5. 3-Switch-OS-Theme.bat
   -> ดับเบิลคลิกเพื่อสลับสไตล์หน้าจอระหว่าง:
      [1] XFCE 4 Desktop  : สไตล์เสมือน Windows (Start Menu ซ้ายล่าง, Taskbar ล่าง)
      [2] PIXEL / LXDE    : สไตล์ออริจินัลของ Raspberry Pi (เมนูด้านบน)

6. 4-Apply-Optimizations.bat
   -> ดับเบิลคลิกเพื่อปรับจูนระบบ ZRAM 100%, ปิด Swap บน SD Card และจูนเคอร์เนล

7. 5-Check-System-Health.bat
   -> ดับเบิลคลิกเพื่อดูอุณหภูมิ CPU, สปีดโหลด, ปริมาณ RAM/ZRAM และพื้นที่ว่าง

8. 6-Backup-Pi-Config.bat
   -> ดับเบิลคลิกเพื่อสำรองข้อมูลการตั้งค่าสำคัญของ Pi เก็บไว้ในโฟลเดอร์ backups
